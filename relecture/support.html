Pour nous aider à comprendre

Indiquez la version d’Orlet, le modèle d’iPhone, la version d’iOS, ce que vous vouliez faire et le message affiché. Une capture avec vos textes et informations personnelles masqués peut être utile. N’envoyez ni mot de passe, ni clé, ni document confidentiel.

Importer depuis Notes ou un document

Depuis Notes ou une app compatible, partagez une sélection de texte ou un fichier vers Orlet. Vérifiez l’aperçu, choisissez Original ou Révision, puis touchez « Préparer dans Orlet ». Ouvrez ensuite Orlet pour confirmer l’import. Le document source reste inchangé ; votre brouillon n’est pas remplacé automatiquement.

Le partage accepte un texte, un fichier TXT ou Markdown UTF-8, un RTF ou un PDF contenant du texte extractible. Il accepte un document ou une sélection à la fois, jusqu’à 10 Mo et 40 000 unités UTF-16 ; un PDF est limité à 100 pages. La mise en page des PDF et RTF n’est pas importée. Les PDF scannés nécessitent un OCR, qui n’est pas inclus. Les fichiers Word ou Pages et les liens de collaboration ne sont pas importés directement : exportez d’abord un format compatible ou partagez une sélection.

Dans l’app, le bouton Importer ouvre les fichiers TXT, Markdown UTF-8 ou un export JSON Orlet. Une erreur de format ou de taille est signalée ; aucun texte n’est tronqué silencieusement.

Conserver et retrouver votre travail

Votre brouillon, la bibliothèque, les versions et les profils sont conservés sur l’appareil. Orlet ne les synchronise pas par iCloud. Exportez votre travail avant de désinstaller l’app ou pour le transférer vers un autre appareil. Les exports JSON contiennent vos textes en clair ; choisissez un emplacement de confiance.

Dans Réglages → Vos documents, « Nouveau brouillon » efface les deux textes et leurs éléments à préserver après confirmation ; les documents et versions de la bibliothèque restent conservés. Si un brouillon ou la bibliothèque ne peut plus être lu, contactez-nous avant de supprimer ses fichiers.

Achats et abonnements Orlet Pro

Pro ajoute la création de documents nommés, leurs versions et la création ou réutilisation de profils. Les deux formules ont les mêmes fonctions : 4,99 € par mois ou 39,99 € par an pour la France, sans essai gratuit. Le prix localisé et la durée fournis par Apple sont affichés dans l’app avant confirmation. La publication sur l’App Store est en préparation ; aucun achat n’est effectué sur ce site.

Pour retrouver un abonnement actif avec le compte Apple utilisé pour l’achat, ouvrez Réglages → « Restaurer les achats », ou le bouton du même nom dans l’écran Pro. La restauration concerne les droits Pro ; elle ne récupère pas les documents locaux supprimés et ne les synchronise pas entre appareils. Si la vérification échoue, réessayez avec une connexion réseau, puis contactez-nous en précisant le message affiché.

Pour gérer ou résilier un abonnement, ouvrez les Réglages de l’iPhone → votre nom → Abonnements → Orlet. Voir l’aide Apple sur la résiliation. Une demande de remboursement se fait auprès d’Apple : demander un remboursement. La désinstallation n’annule pas l’abonnement. Après l’expiration de Pro, vos documents existants restent lisibles, ouvrables, récupérables en copies et exportables ; vos profils restent lisibles.
